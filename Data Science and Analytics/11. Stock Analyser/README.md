# 📈 Stock Data Scraper for ASX Fundamental Analysis

This project automates the extraction of historical fundamental data for publicly traded companies listed on the Australian Securities Exchange (ASX). It is designed to support deep, professional-grade equity research and long-term portfolio construction.

## 🔍 Key Focus Areas

- **Growth**: Revenue, EPS, EBITDA, Book Value CAGR over multiple years
- **Profitability**: Margins (EBITDA, Net, Operating), ROE, ROA
- **Financial Strength**: Leverage, liquidity ratios, net debt
- **Cash Flow**: Free Cash Flow, FCF margin, Cash Conversion Ratio
- **Valuation**: P/E, P/B, PEG analysis
- **Operational Efficiency**: CapEx-to-Revenue, Cash Conversion Cycle

## 🔧 Features

- Automated scraping of structured financial data
- Multi-year historical data processing
- Normalized metrics to allow fair cross-company and cross-sector comparison
- Foundation for sector-based portfolio building and investment ranking

## 💼 Use Case

This notebook supports a broader investment framework that evaluates companies pillar-by-pillar, combining accounting rigor and strategic long-term positioning. It is ideal for analysts, investors, or developers building financial models or stock screeners focused on ASX equities.

## ⚙️ Requirements

- Python 3.8+
- pandas, BeautifulSoup, requests

## 📁 Structure

- `Stock Data Scrapper.ipynb`: Main notebook for scraping and organizing ASX financial data
- `data/`: Optional folder to store raw or processed outputs
